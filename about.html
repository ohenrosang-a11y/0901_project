About

사용하기 쉬운 화면을 만드는 데 집중합니다.

사용자가 편하게 이해하고 사용할 수 있는 웹 인터페이스를 만드는 데 관심이 있습니다. 작은 레이아웃과 인터랙션의 차이가 전체 경험을 바꾼다고 생각합니다.

복샘

프론트엔드 개발자

  • 관심 분야: 웹 UI, 접근성, 인터랙션
  • 주요 기술: JavaScript, CSS, React, Apps Script
  • 이메일: boksem@example.com

학습 방향

HTML 시맨틱 구조, CSS 반응형 레이아웃, JavaScript DOM 조작을 중심으로 기본기를 다지고 있습니다.

개발 관심사

사용자가 정보를 빠르게 파악할 수 있는 구조, 접근성, 유지보수하기 쉬운 코드에 관심이 있습니다.

목표

기본 웹 기술을 탄탄히 익힌 뒤 최신 프론트엔드 프레임워크와 클라우드 서비스까지 확장해 실제 가치를 제공하는 개발자가 되는 것입니다.
